# 🦇 Batman Logo — 3D CAD Design (Onshape)

Welcome to the **Batman Logo 3D Modeling Project**. This repository contains a precise and fully constrained 3D CAD model of the iconic Batman logo, designed from scratch using **Onshape**.

This project highlights best practices in parametric 3D modeling, geometric constraints, feature tree organization, and preparation for additive manufacturing (3D printing).

---

## 🛠️ Design & Technical Highlights

* **Parametric Sketching:** Designed using fully defined sketch relations and geometric constraints to preserve accurate proportions.
* **Symmetry & Balance:** Leveraged mirroring operations along primary reference planes to ensure flawless left-to-right symmetry.
* **Clean Feature Tree:** Organized feature hierarchy for straightforward modifications, parameter scaling, and design iterations.
* **Manufacturing Readiness:** Optimized geometries suited for CNC machining, laser cutting, or direct **3D Printing (STL / STEP)**.

---

## 📂 Included File Formats

* **`.STEP` / `.STP`**: Universal CAD format compatible with SolidWorks, Fusion 360, Inventor, and Rhino.
* **`.STL`**: Slicer-ready format optimized for FDM / SLA 3D printing.
* **Onshape Cloud Access**: Interactive, full-definition model accessible directly via web browser.

---

## 🚀 How to Use / Import

1. **Clone or Download** this repository.
2. **For CAD Editing:** Import the `.STEP` file into your preferred 3D software or copy the document via the Onshape link above.
3. **For 3D Printing:** Load the `.STL` file into your slicer software (PrusaSlicer, Cura, Bambu Studio) and slice according to your printer's specifications.
